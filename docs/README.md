# Документы АМС Старт

Минимальный canon starter-репозитория:

- `PRODUCT.md` — назначение шаблона и границы производного продукта;
- `ARCHITECTURE.md` — модульная карта и dependency rules;
- `DATA_MODEL.md` — нейтральная Prisma-модель;
- `AUTH.md` — роли, вход и provisioning;
- `SECURITY.md` — PII, service worker, секреты и trust boundaries;
- `ENVIRONMENT.md` — переменные окружения;
- `RUNBOOK_DEPLOY.md` — reusable release/deploy контур;
- `EXTERNAL_SITE_DESIGN_SYSTEM.md` — публичный слой, footer, legal, login modal;
- `INTERNAL_DASHBOARD_DESIGN_SYSTEM.md` — приватный shell, таблицы, формы, состояния;
- `MASTER_PLAN.md` — короткий backlog следующего product derivation.

Starter не содержит отраслевой пример. Доменная модель, интеграции, тарифы, юридические тексты и production topology добавляются отдельным stream в производном продукте.
